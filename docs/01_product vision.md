# Product Vision
---
## Overview

A CSS-first, framework-agnostic component system designed to provide composable UI primitives, token-driven theming, and a high-quality developer experience through interactive documentation.

## Problem

Most UI libraries force tradeoffs:

- Fully styled systems are rigid and difficult to customize
- Headless systems require excessive effort to implement
- Utility-first approaches lack structure and consistency
- CSS libraries often lack strong documentation and DX

## Solution

Provide a system that:

- Uses pure CSS + tokens as the foundation
- Enables composition over monolithic components
- Supports any framework or no framework
- Offers interactive documentation (Storybook)
- Balances usability and flexibility

## Target Users

- Individual developers building products
- Startup teams without a full design system
- Design system teams needing a foundation
- Backend-heavy teams using server templates
- Developers avoiding framework lock-in

## Value Proposition

- Works everywhere (HTML → React → Django → Astro)
- Easy to override and theme
- Predictable and consistent API
- High-quality documentation and playground
- Scales from small apps to enterprise systems

## Non - Goals

- Not a JS-heavy UI framework
- Not tied to React or any single ecosystem
- Not a utility-first framework replacement
- Not a fully opinionated design system

## Success Criteria

- Developers can adopt without rewriting architecture
- Components are easily themeable without hacks
- Documentation enables rapid onboarding
- Library is used across multiple frameworks
